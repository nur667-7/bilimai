# DESIGN.md — BilimAI Design System (Современный учебник с деталями учебной тетради)

## 1. Направление и характер
**«Современный учебник с небольшими деталями учебной тетради»:**
- **Спокойный тёплый светлый фон бумаги:** `--background: #F7F5F0`, без градиентных сеток, неоновых свечений и стеклянных плашек.
- **Одна рабочая поверхность для основного занятия (`.surface`):** Чистый лист (`#FFFFFF`, `border: 1px solid #E2DDD3`, `border-radius: 10px`). Внутри листа порядок создаётся отступами, тонкими линиями и типографикой, а не вложенными карточками:
  - Список тем слева (`.topics`) — открытое оглавление на полях без отдельной рамки-карточки.
  - Главное правило (`.rule`) — спокойная тёплая подложка (`#F8F6F1`) с тонким акцентом слева (`3px solid #1B3B6F`).
  - Формула (`.equation`) — центр экрана, крупная и без обводки-коробки.
  - Шаги решения (`.steps li`) — нумерованные строки с тонкой пунктирной тетрадной линией (`1px dashed #E5E0D5`).

## 2. Типографика и математика как главный элемент
- **Заголовки тем и разделов (`--font-serif`):** `"Newsreader", "Iowan Old Style", "Palatino Linotype", "Book Antiqua", Georgia, serif`, `font-weight: 500`, без тяжёлого `800` полужирного начертания.
- **Формулы и условия задач (`--font-math`):** `"STIX Two Math", "Cambria Math", "Times New Roman", Georgia, serif`, `clamp(26px, 3.4vw, 36px)` для главного примера урока (`.equation`) и `clamp(20px, 2.4vw, 25px)` для условия задачи в практике (`.practice-math-stem`).
- **Обычный текст и элементы управления (`--font-sans`):** Спокойный гротеск (`-apple-system, BlinkMacSystemFont, "Inter", "Segoe UI", sans-serif`) с `font-variant-numeric: tabular-nums` для номеров задач, шагов и баллов.
- **Один глубокий учебный акцент (`--primary: #1B3B6F`):** Используется только для главного действия на экране и отметки выбранного элемента.

## 3. Разделение действий по назначению
- **В шапке (`.site-header`):** Переход между разделами продукта (`Занятие`, `Карта тем`, `Пробное ЕНТ`, `Мой план`, `Тренировка ошибок`), ссылка `О проекте` и переключатель языка (`RU / ҚАЗ / OʻZB`).
- **В списке тем (`.topics` / `.mobile-topic-select`):** Выбор темы курса (`01..10`).
- **Внутри занятия (`.lesson-tabs`):** Только 3 спокойных этапа текущего урока — `Разбор`, `Практика`, `Задать вопрос`.
- **В конце каждого этапа (`.stage-next-step`):** Один понятный следующий шаг:
  - После разбора примера → **«Решить самостоятельно»**
  - После ошибки в практике → **«Разобрать ошибку»** и **«Попробовать ещё раз»**
  - После верного ответа → **«Следующая задача»**

## 4. Язык интерфейса и обучающая обратная связь
- Простые и понятные школьнику названия: **«Карта тем»**, **«Задать вопрос»**, **«Главное правило»**, **«Практика»** (`Задача 1 из 3`).
- Обратная связь рядом с ответом объясняет конкретную математическую причину ошибки в выбранном дистракторе (`getOptionFeedback`), а в `/lab` пояснение и подсказка открываются прямо под выбранным шагом (`.step-inline-feedback`).

## 5. Отдельная мобильная композиция (`390px`)
- Строго нулевой горизонтальный скролл (`scrollWidth === 390` на `390×844`): компактная шапка, выпадающий список темы, 3 вкладки внутри занятия и крупная формула на первом экране.
